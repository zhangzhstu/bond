# BOND

Prediction.** Zihang Zhang, Jiayi Li, Yanan Sun, Jiujun Cheng, Zhenyu Lei, Shangce Gao.
Under review at KDD 2027 (AI for Science track).

- Project page: <https://zhangzhstu.github.io/bond/>
- Paper: [`bond-paper.pdf`](bond-paper.pdf) (submitted version)
- Code: [`code/`](code/), with training, evaluation under each meta-test protocol and the
  geometry measurements; see [`code/README.md`](code/README.md)

The project page is `index.html` at the repository root, a single HTML file with no build step,
served by GitHub Pages.
